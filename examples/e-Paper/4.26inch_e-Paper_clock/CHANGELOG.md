### 工作流程

1. **启动阶段**
   - 初始化日志系统
   - 初始化网络服务（KV、定时器、TLS）
   - 订阅网络状态事件
   - 初始化网络管理器
   - 连接 WiFi

2. **时间同步阶段**
   - 等待网络连接（最多 30 秒）
   - 发送 HTTP 请求到时间服务器
   - 解析响应头中的 Date 字段
   - 计算时间偏移
   - 标记同步成功

3. **显示阶段**
   - 初始化 e-Paper 显示屏
   - 显示标题和同步状态
   - 进入循环：
     - 获取当前时间（应用偏移）
     - 格式化显示字符串
     - 居中绘制到屏幕
     - 部分刷新显示
     - 等待 1 秒

### 时间服务器

默认使用 WorldTimeAPI：
- URL: `worldtimeapi.org`
- Path: `/api/timezone/Asia/Shanghai`
- 支持 HTTP 和 HTTPS

可以更改为其他时间服务器，只需修改宏定义。

### 依赖项

新增依赖：
- `http_client_interface.h` - HTTP 客户端
- `netmgr.h` - 网络管理器
- `netconn_wifi.h` - WiFi 连接（如果启用）
- `tal_api.h` - Tuya 抽象层 API

### 兼容性

- ✅ 向后兼容：如果网络不可用，使用本地时间
- ✅ 优雅降级：同步失败时继续使用本地时间
- ✅ 状态指示：清楚显示是否已同步

### 已知限制

1. WiFi 凭据需要硬编码在代码中
2. 时间服务器 URL 需要在编译时确定
3. 需要网络连接才能同步时间
4. 首次同步可能需要 30 秒
