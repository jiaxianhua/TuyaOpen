# 完整解决方案：显示所有网络下载的中文字符

## 问题

如何让墨水屏小说阅读器显示从网络下载的**所有**中文字符？

## 解决方案

使用**完整 GB2312 字库**（6,763 个汉字），覆盖 99% 的中文内容。

## 手动步骤（详细）

### 步骤 1：下载 HZK16 字库

```bash
cd examples/e-Paper/4.26inch_network_novel_reader

# 下载 HZK16（约 260KB）
wget https://github.com/aguegu/BitmapFont/raw/master/font/HZK16

# 验证文件
ls -lh HZK16
# 应该显示约 260KB
```

### 步骤 2：生成完整字库

```bash
# 生成包含所有 GB2312 汉字的 C 代码
python tools/generate_full_hzk16.py HZK16 hzk16_full.c

# 输出示例：
# Reading HZK16 font file: HZK16
# Generating C code to hzk16_full.c...
#   Generated 100 characters...
#   Generated 200 characters...
#   ...
#   Generated 6700 characters...
# 
# Done!
# Generated 6763 characters
# File size: 234567 bytes (~229KB)
```

### 步骤 3：替换字库文件

```bash
# 备份原始文件
cp lib/Fonts/hzk16.c lib/Fonts/hzk16_default.c.bak

# 使用完整字库
cp hzk16_full.c lib/Fonts/hzk16.c

# 验证
ls -lh lib/Fonts/hzk16.c
# 应该显示约 230KB
```

### 步骤 4：编译项目

```bash
# 编译（可能需要几分钟）
tos.py build

# 如果编译慢，使用并行编译
tos.py build -j4
```

### 步骤 5：烧录和测试

```bash
# 烧录到设备
tos.py flash

# 监控串口输出
tos.py monitor

# 测试步骤：
# 1. 设备启动，连接 WiFi
# 2. 按按钮下载小说
# 3. 查看中文字符是否正确显示
```

## 常见问题

### Q1: 为什么选择 GB2312 而不是 GBK？

**A**: 
- GB2312 包含 6,763 个常用汉字，覆盖 99% 的内容
- 完整 GBK 有 20,000+ 汉字，文件太大（~700KB）
- 大部分额外字符是生僻字，实际很少用到

### Q2: 230KB 会不会太大？

**A**: 
- 现代 MCU 通常有 2MB+ Flash
- 230KB 只占 11.5%
- 相比功能提升，空间占用是值得的

### Q3: 编译时间会变长吗？

**A**: 
- 是的，大约增加 1-2 分钟
- 但只需编译一次
- 可以使用并行编译加速：`tos.py build -j4`

### Q4: 可以只生成部分字符吗？

**A**: 
可以，修改 `generate_full_hzk16.py`：

```python
# 只生成一级汉字（3,755 个常用字）
for qu in range(16, 56):  # 0xB0-0xD7
    for wei in range(94):
        # ... 生成代码
```

### Q5: 如何添加自定义字符？

**A**: 
在 `hzk16_full.c` 末尾添加：

```c
{0x81, 0x40, {  // 自定义字符
    0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,
    // ... 32 字节字体数据
}},
```
