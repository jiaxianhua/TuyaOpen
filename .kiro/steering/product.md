# TuyaOpen Product Overview

TuyaOpen is a cross-platform C/C++ SDK for building AI-powered IoT hardware. It enables developers to create smart devices with multimodal AI capabilities (voice, vision, sensors) that integrate with Tuya Cloud services and leading LLM platforms.

## Key Capabilities

- **AI Integration**: ASR, KWS, TTS, STT speech technologies; integration with ChatGPT, Claude, Gemini, Deepseek, Qwen, Doubao
- **IoT Connectivity**: Bluetooth, Wi-Fi, Ethernet, cellular support
- **Cloud Services**: Remote control, monitoring, OTA updates via Tuya Cloud
- **Smart Home**: Compatible with Google Home and Amazon Alexa
- **Security**: Built-in device authentication and data encryption

## Target Platforms

Supports Tuya T-Series MCUs (T2, T3, T5), ESP32 variants, Raspberry Pi, BK7231N, LN882H, and Ubuntu/Linux hosts.

## Use Cases

Smart home products, industrial IoT solutions, custom AI applications, "Powered by Tuya" hardware.
